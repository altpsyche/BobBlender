# Handover: terrain generator redesign

Paste-ready brief for a fresh chat. Plain house style (no em-dashes, no emojis, no flowery phrasing).

## The problem, in one line

The terrain presets are knob positions on one noise-plus-fluvial generator, so most of them render as
generic eroded hills. Canyon does not read as a canyon, Mesa does not read as a mesa, Badlands and
Plateau look like Hills. The artist has lost faith in the terrain system. Read docs/TERRAIN-CRITIQUE.md
first; it is the full diagnosis. This handover is the work order.

## Hard rule, learned the hard way

Do NOT judge terrain by scalar statistics. Height histograms, gradient percentiles, laplacian, and
pairwise correlation all went green in the last session while the output stayed generic. Correlation
tells you two fields differ from each other, not that either one is the landform on its label.

Every terrain claim must be backed by a 3D render you actually look at, plus a landform-diagnostic
measurement (defined below). Render-in-the-loop is mandatory, not optional. If you cannot show a render
that reads as a canyon, you have not made a canyon.

## What the system is

A terrain recipe is an ordered op stack evaluated by `engine.run_stack` on a float heightfield. The
whole engine is pure numpy/cupy and runs headless with no Blender. Key files, all under
`tools/bobtools/heightfields/`:

- `generate.py` `generate_base`: the ridged/warped multifractal noise base. This one shape is the
  skeleton of every non-dune preset, which is the core problem.
- `ops_generate.py`: dunes (rewritten last session, good), voronoi (distance field, not flat cells).
- `ops_erode.py`: fluvial (stream-power, the dominant op and the homogenizing attractor), thermal,
  deposit, pipe_hydraulic.
- `ops_filter.py`: terrace (rewritten last session to make flat treads), curve, sharpen, falloff.
- `engine.py`: `run_stack`, the op registry, per-op selector masks.
- `params.py`: `resolve_stack` maps the five global knobs (Relief/Detail/Erosion/Warp/Seed) onto a
  preset stack; also `_preset_salt` (added last session) so presets do not share a base seed.
- `presets.py`: the `STACKS` dict (source of truth), `DISPLAY` (per-preset height/sea_level),
  `FAMILIES`.

Panel and build side:

- `blender/extensions/bob_blender_tools/__init__.py`: the Terrain panel, the Bake+Build operator, the
  `_run_host_bake` subprocess runner, `_OP_ADD_DEFAULTS`.
- `blender/extensions/bob_blender_tools/presets.json`: a committed MIRROR of presets.py, generated by
  `tools/scripts/gen_panel_presets.py`. Regenerate it after any presets.py change with
  `PYTHONPATH=tools python tools/scripts/gen_panel_presets.py`. Do not hand-edit it.
- `blender/bbmcp/geonodes/recipes/heightmap_terrain.py`: the GN build. It just displaces a grid by the
  baked PNG: `z = (heightfield - sea_level) * height`. Proportion (height, sea_level) is applied HERE,
  decoupled from the generator, which is one of the flaws.

## Headless verify pattern (this works, reuse it)

Bake a field with pure python (has numpy/scipy/pillow via the terrain extra):

```
cd /home/siva/dev/BobBlender
uv run --extra terrain --project tools python <script>
# in the script:
import sys; sys.path.insert(0, "tools")
from bobtools.heightfields import backend, engine, params
be = backend.CpuBackend()
p = params.build_params({"preset": "canyon", "size": 512})
h = engine.run_stack(np.zeros((512,512)), p["stack"], be, seed=p["seed"])  # h in [0,1]
# save 16-bit PNG for the Blender build
```

Then build and RENDER the mesh in Blender (this is what the artist sees):

```
~/.steam/steam/steamapps/common/Blender/blender --background --factory-startup --python <script>
# in the script: put blender/ and blender/extensions/ on sys.path, then
from bbmcp.dispatch import apply_op
apply_op({"op":"reload_image","path":PNG})
apply_op({"op":"build_geonodes","recipe":"heightmap_terrain","name":"Terrain",
          "params":{"heightmap":PNG,"size":90.0,"resolution":384,"height":H,"sea_level":S}})
# add a camera + sun, set EEVEE, render to PNG, then read the PNG back and LOOK at it.
```

Blender's bundled python does not have PIL or scipy. Bake and save PNGs in the uv env; only build and
render in Blender. The venv bobtools is an editable install, so engine edits are picked up by the bake
subprocess with no reinstall.

Tests: `uv run --extra terrain --with pytest --project tools python -m pytest tools/tests/test_heightfields.py -q`.
The golden (`tools/tests/data/golden_hf.npy`) runs an explicit stack, not a preset, so retuning presets
does not require regenerating it. Regenerate only on intentional op-math changes with
`tools/tests/data/make_golden.py`.

## The mandate

Fix the generators, not the sliders. Per docs/TERRAIN-CRITIQUE.md section "Recommendations":

1. Define a landform-diagnostic per family, a measurable feature that says "this is the landform":
   - Mesa: fraction of area that is near-flat cap sitting directly above near-vertical cliffs.
   - Canyon: confined steep-walled channels incised below flat surrounding rims.
   - Badlands: high drainage density at low overall relief.
   - Dunes: asymmetric slip faces near the angle of repose (about 34 degrees). Dunes already passes.
   Build these as functions that take a heightfield and return a number, and gate each preset on its
   own diagnostic plus a render.

2. Give the process-driven landforms their own generators instead of filtering shared noise:
   - Mesa/plateau: flat layered strata plus a resistant cap, eroded by cliff/scarp retreat. Not
     dendritic fluvial.
   - Canyon: incise a confined channel network into a high near-flat uplifted surface, keep the rims
     flat. Reuse the existing fluvial hero but feed it a plateau, not a hill.
   - Badlands: dense fine rill erosion on soft low-relief sediment.
   - Mountains and dunes already work; leave them.

3. Make proportion part of the landform, either by coupling a height range into each generator or by
   clamping so a preset cannot be flattened or stretched into nonsense.

4. Be honest about the menu. If a landform is not real yet, do not offer its name. A smaller honest
   preset list beats a big list of look-alikes. Confirm with Siva before removing or renaming any
   preset, since the names are user-facing.

## State from the last session (do not redo, do not trust blindly)

Committed nowhere yet; changes are in the working tree on branch `fix/audit-remediation`.

- Dunes and Sand Sea: rewritten and genuinely fixed, verified in 3D. `ops_generate.dunes` is now an
  asymmetric transverse-dune profile; defaults dropped to frequency 3 (dunes) / 2 (sand_sea), height 6
  / 8. Keep this.
- `ops_filter.terrace`: rewritten to produce flat treads with sharp risers (it previously could not
  flatten a tread at all). Keep this; it is a genuine improvement, though terrace remains a post-hoc
  filter, not real strata.
- `params.resolve_stack`: added `_preset_salt` so presets do not share a base noise seed. Keep.
- `presets.py` canyon/mesa/badlands/plateau stacks were retuned to decorrelate them. This reduced
  correlation to about zero but did NOT make them read as their landforms. Treat these four stacks as
  provisional; the redesign should replace their generators, not tune them further.

## Decision taken 2026-07-22: honest menu, Canyons family cut

Siva chose the honest-menu path over a generator rebuild for now. The four look-alike presets were
removed rather than demoted:

- Cut `canyon`, `mesa`, `badlands`, `plateau` from `presets.py` (STACKS, DISPLAY, FAMILIES) and the
  regenerated `presets.json`. The whole Canyons family is gone; families are now Mountains, Lowlands,
  Dunes, nine presets total.
- The panel builds its dropdown from `presets.json`, so it just shows nine now; no panel enum was
  hardcoded. `_preset_salt` hashes the name, so nothing broke.
- Tests: retargeted the three canyon-preset tests to `alpine` (the strongest surviving fluvial carver).
  Removed the below-local-mean channel-fraction test; it was tuned to the deep canyon hero and the
  gentler mountains do not separate on that proxy. Channel formation is still asserted by
  `test_flow_map_concentrates` (drainage concentration on `alpine`). 38 pass.

Not done, still open for the redesign: the real generators (strata, cap-rock, scarp retreat) that would
let canyon/mesa/badlands/plateau come back as their actual landforms, and the per-family diagnostics.
The names are free to reuse when the generators exist.
